# 向量 — 空间的坐标与方向

一条箭头从原点出发，指向空间中的一个点——这是向量最简单的样子。但线性代数要问的是：**为什么这一个简单的对象，能成为理解整个空间的起点？** 答案在于「组合」：任何向量都能由几个基向量拼出来，而空间的结构就藏在这些拼法里。

## 向量的两种身份

向量 $\mathbf{v} = (x, y)$ 有双重身份：

- **几何上**：一条从原点出发的箭头，长度 $\|\mathbf{v}\| = \sqrt{x^2 + y^2}$，方向指向 $(x,y)$
- **代数上**：一个有序数组，可以被加减、被数乘

这两种身份的转换——把抽象的数组想象成有方向的箭头——是线性代数最重要的思维习惯。

## 线性组合：拼出整个空间

> $$\mathbf{v} = x\mathbf{i} + y\mathbf{j}$$

**线性组合**是向量的核心运算：把几个向量分别乘上标量再相加。两个基本动作足够生成一切：

- **向量加法** $\mathbf{u} + \mathbf{v}$ = 平移（把 $\mathbf{u}$ 的终点作为 $\mathbf{v}$ 的起点）
- **数乘** $c\mathbf{v}$ = 缩放（$c$ 倍拉长或压短，$c<0$ 时反向）

## 基与线性无关

如果一组向量**线性无关**（没有任何一个是其他几个的组合），且能**张成**整个空间，它们就是一组**基**。标准的 $\{\mathbf{i}, \mathbf{j}\}$ 是最简单的基，但空间里有无穷多种基。

关键洞察：**基的个数 = 空间的维数**。$n$ 个线性无关的 $n$ 维向量构成的矩阵，行列式必不为 0。

## 从向量到空间

$$n \text{ 个线性无关向量 } \Rightarrow \text{ 张成 } n \text{ 维空间}$$

一旦接受了「几个向量能张成一个空间」，你就拥有了理解矩阵、线性变换、特征值的地基——因为矩阵不过是「把基向量搬到哪去了」的记录。
