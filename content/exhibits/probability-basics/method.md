## 破局心法：概率空间的解题思路

### 1. 先画样本空间

几乎所有概率题的第一步都是**明确样本空间**：所有可能结果是什么？是否等可能？

- 古典概型：结果有限且等可能 → $P = \frac{|A|}{|\Omega|}$
- 几何概型：结果连续 → $P = \frac{\text{面积}}{\text{总面积}}$
- 不要漏掉结果，不要重复计数

### 2. 判断独立性

两事件是否独立？**独立才可相乘**：

$$P(A\cap B) = P(A)P(B) \quad (\text{仅当 A、B 独立})$$

不独立时用条件概率：$P(A\cap B) = P(A)P(B|A)$。

### 3. 条件概率优先用定义

$$P(A|B) = \frac{P(A\cap B)}{P(B)}$$

先找交集，再除以条件事件概率。**不要凭直觉估计条件概率**——很多反直觉问题都源于此。

### 4. 随机变量：先分布后计算

涉及随机变量的题目，先确定分布类型：

| 类型 | 关键公式 |
|------|---------|
| 二项分布 $B(n,p)$ | $P(X=k) = \binom{n}{k}p^k(1-p)^{n-k}$，$E=np$ |
| 泊松分布 | $P(X=k)=\frac{\lambda^k e^{-\lambda}}{k!}$ |
| 均匀分布 | $E=\frac{a+b}{2}$ |
| 正态分布 | 标准化 $Z=\frac{X-\mu}{\sigma}$ |

### 5. 期望与方差的计算

期望是加权平均，可线性：$E[aX+b] = aE[X]+b$；方差 $Var(X) = E[X^2] - (E[X])^2$。

### 常见陷阱

1. **忘记独立性检查**就直接相乘
2. **混淆 $P(A|B)$ 与 $P(B|A)$**（医学检验题经典陷阱）
3. **样本空间不清**导致计数错误
4. **期望值不是"最可能值"**——期望是加权平均
