## 破局心法：特征值的解题思路

### 1. 特征值问题三步走

求 $A$ 的特征值和特征向量：

1. 解特征方程 $|A - \lambda I| = 0$ → 得特征值 λ
2. 对每个 λ，解齐次方程 $(A-\lambda I)v = 0$ → 得特征向量
3. 特征向量的个数 ≤ 特征值的重数；可对角化 ⟺ 每个特征值有足够多的线性无关特征向量

### 2. 快速识别特殊矩阵的特征值

- **对角矩阵**：特征值 = 对角线元素
- **三角矩阵**：特征值 = 对角线元素
- **对称矩阵**：特征值全为实数
- **单位矩阵**：特征值全为 1（任何非零向量都是特征向量）

### 3. 用迹与行列式检查

$$\text{tr}(A) = \lambda_1 + \cdots + \lambda_n, \qquad \det(A) = \lambda_1 \cdots \lambda_n$$

两个守恒律用于验证：所有特征值之和 = 迹，所有特征值之积 = 行列式。

### 4. 特征值的应用判据

- 求 $A^n$：对角化后 $A^n = PD^nP^{-1}$，只沿对角元素取幂
- 判断稳定性：矩阵的最大特征值模决定动力系统的收敛/发散
- 可逆性：$A$ 可逆 ⟺ 0 不是 $A$ 的特征值

### 常见陷阱

1. **特征向量漏掉零向量**：特征向量必须非零
2. **重特征值计数**：代数重数（特征方程中幂次）≠ 几何重数（线性无关特征向量个数）
3. **对角化条件**：$n$ 阶矩阵可对角化 ⟺ 有 $n$ 个线性无关特征向量——重特征值可能破坏它
4. **实矩阵未必有实特征值**：旋转矩阵的特征值是复数 $e^{\pm i\theta}$
