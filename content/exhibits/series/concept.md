# 无穷级数 — 无限的拼图

如果把一块蛋糕对半切，再对半切……你吃掉每一块，总共能吃多少？答案是"整块"——$\frac12+\frac14+\frac18+\cdots = 1$。**无穷多个数相加，结果却可能是有限的。**级数研究的就是：这种"无限相加"什么时候收敛、收敛到什么值、以及如何用它逼近复杂函数。

## 收敛：部分和的极限

级数 $\sum_{n=1}^{\infty} a_n$ 是否收敛，看的是**部分和** $S_N = a_1 + \cdots + a_N$：

> 级数收敛 ⇔ 部分和数列 $\{S_N\}$ 的极限存在

注意：$a_n \to 0$ 是收敛的**必要条件但非充分**——调和级数 $\sum \frac1n$ 每一项都趋于 $0$，却发散。判断正项级数收敛与否，有四件武器：

| 方法 | 思路 |
|------|------|
| **比较判别法** | 与已知级数比较 $a_n \le Cb_n$ |
| **比值判别法** | $\lim \left|\frac{a_{n+1}}{a_n}\right| = \rho < 1$ 收敛 |
| **根值判别法** | $\lim \sqrt[n]{|a_n|} = \rho < 1$ 收敛 |
| **积分判别法** | 与反常积分比较 $\int_1^\infty f(x)\,dx$ |

## 幂级数：在收敛半径内就是一个函数

> $$f(x) = \sum_{n=0}^{\infty} c_n(x-a)^n$$

每个幂级数都有**收敛半径** $R$：$|x-a| < R$ 内绝对收敛，$|x-a| > R$ 外发散，$|x-a|=R$ 处需单独判断。在收敛域内，这个无穷多项式完全就是一个函数——泰勒级数 $f(x)=\sum \frac{f^{(n)}(a)}{n!}(x-a)^n$ 就是它的特例，用多项式逐点逼近函数。

## 傅里叶级数：用正弦波雕刻任何周期函数

> $$f(x) = \frac{a_0}{2} + \sum_{n=1}^{\infty}\left[a_n\cos(nx) + b_n\sin(nx)\right]$$

任何"合理"的周期函数，都能写成不同频率正弦波与余弦波的叠加。你每加一个谐波，叠加结果就更逼近目标波形——但注意，在间断点附近总有一个约 **9% 的过冲**，且不随项数增加而消失：这就是**吉布斯现象**。

这是信号处理、图像压缩、声音合成的数学基础。
