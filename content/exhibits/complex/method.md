## 破局心法：复分析解题思路

### 1. 先验证解析性：柯西-黎曼方程

复函数 $f = u + iv$ 解析（在某点可微）的充要条件是**柯西-黎曼方程**：

$$\frac{\partial u}{\partial x} = \frac{\partial v}{\partial y}, \quad \frac{\partial u}{\partial y} = -\frac{\partial v}{\partial x}$$

先检查 C-R 方程是否成立，再判断是否可微。若 $u,v$ 有连续偏导且满足 C-R，则 $f$ 在该点解析。

### 2. 解析函数的基础运算

把 $z$ 拆成实虚部再套定义太慢，记住几条直接结论：

- 多项式、$e^z$、$\sin z$、$\cos z$ 在全平面解析
- $\log z$、$z^\alpha$ 在（去掉割线的）区域上解析
- $1/z$ 除 $z=0$ 外解析——$0$ 是它的极点

### 3. 留数定理：三步走

计算闭合路径积分 $\oint_C f(z)dz$：

1. 找出 $C$ 内所有奇点（孤立奇点）
2. 在每个奇点计算留数 $\mathrm{Res}(f, z_0)$：
   - 简单极点：$\mathrm{Res} = \lim_{z\to z_0} (z-z_0)f(z)$
   - $m$ 阶极点：$\mathrm{Res} = \frac{1}{(m-1)!}\lim_{z\to z_0}\frac{d^{m-1}}{dz^{m-1}}[(z-z_0)^m f(z)]$
3. 结果：$\oint_C f(z)dz = 2\pi i \sum \mathrm{Res}$

### 4. 实积分 → 围道积分

计算 $\int_{-\infty}^{\infty} f(x)dx$ 型积分：

- 选择合适的闭合围道（上半圆/矩形/楔形）
- 验证圆弧部分在半径→∞时积分→0（通常用 ML 不等式估计）
- 用留数定理算整个围道，取实部或虚部

常用：$\int_0^{2\pi}$ 三角有理函数 → 令 $z=e^{i\theta}$ 化为单位圆上的积分。

### 5. 洛朗级数：奇点附近的行为

在奇点附近展开洛朗级数 $\sum a_n(z-z_0)^n$：

- 无负幂 → 可去奇点
- 有限个负幂 → 极点（最高负幂的绝对值 = 阶）
- 无穷多负幂 → 本性奇点（$e^{1/z}$ 在 0 处）

**$1/(z-z_0)$ 的系数就是留数**——这是找留数的另一条路。

### 常见陷阱

1. **C-R 方程是必要条件也是充分条件**——但前提是 $u,v$ 有连续偏导，否则需额外检查
2. **围道积分忘检查奇点是否在围道内**：$\oint_C f dz$ 只与围道内的奇点有关
3. **把本性奇点当极点**：$e^{1/z}$ 在 0 处没有洛朗展开的有限主部
4. **实积分取虚部时忘了单位**：有时答案是纯虚数或需要 $\pi$ 的倍数
