## 破局心法：矩阵的解题思路

### 1. 解方程组：消元 vs 逆矩阵

解 $Ax=b$ 的两种视角：

- **消元法**：对增广矩阵做初等行变换，化为阶梯形 → 得到解（数值稳定，实际常用）
- **逆矩阵法**：$x = A^{-1}b$（仅当 $A$ 可逆，即 det ≠ 0）

### 2. 行列式的计算策略

$$|A| = ad - bc \quad (2\times2)$$

高阶行列式优先用**初等变换化简**：
- 某行乘以 $k$ → 行列式乘 $k$
- 两行交换 → 行列式变号
- 某行加上另一行的倍数 → 行列式不变
- 化为上三角 → 行列式 = 对角元乘积

### 3. 矩阵的秩与可逆

矩阵的**秩** = 线性无关的行（或列）的最大个数：
- 满秩（rank = n）：$Ax=b$ 有唯一解，$A$ 可逆
- 缺秩：无穷多解或无解，自由变量个数 = n − rank

可逆 ⟺ det ≠ 0 ⟺ 满秩 ⟺ 列向量线性无关。

### 4. 矩阵乘法的顺序

$AB$ 表示「先做 $B$ 再做 $A$」——**矩阵乘法不满足交换律**：$AB \neq BA$。但满足结合律：$(AB)C = A(BC)$，所以可以按最省计算量的顺序分组。

### 常见陷阱

1. **矩阵乘法不满足交换律**：$AB \neq BA$，顺序不能随意换
2. **消元时混淆行变换和列变换**：解方程只能用行变换
3. **可逆条件记错**：可逆 ⟺ det ≠ 0 ⟺ 满秩 ⟺ 列向量线性无关
4. **把 $AB = 0$ 当 $A=0$ 或 $B=0$**：矩阵乘法没有「零因子」性质，$AB=0$ 不代表任一为 0
