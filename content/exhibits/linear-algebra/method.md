## 破局心法：线性代数解题思路

### 1. 先判断：是线性还是非线性

线性系统满足两条：加法封闭、数乘封闭。看到 $Ax=b$、矩阵、向量空间——都是线性。**线性意味着可以叠加，可以用矩阵统一处理**。

### 2. 解方程组：消元 vs 逆矩阵

解 $Ax=b$ 的两种视角：

- **消元法**：对增广矩阵做行变换（初等行变换），化为阶梯形 → 得到解
- **逆矩阵法**：$x = A^{-1}b$（仅当 A 可逆，即 det ≠ 0）

实际中消元法更常用（数值稳定），逆矩阵适合理论推导。

### 3. 行列式的计算策略

$$|A| = ad - bc \quad (2\times2)$$

高阶行列式优先用**初等变换化简**：
- 某行乘以 k → 行列式乘 k
- 两行交换 → 行列式变号
- 某行加上另一行的倍数 → 行列式不变
- 化为上三角 → 行列式 = 对角元乘积

### 4. 特征值问题三步走

求 A 的特征值和特征向量：

1. 解特征方程 $|A - \lambda I| = 0$ → 得特征值 λ
2. 对每个 λ，解齐次方程 $(A-\lambda I)v = 0$ → 得特征向量
3. 特征向量的个数 ≤ 特征值的重数；可对角化 ⇔ 每个特征值有足够多的线性无关特征向量

### 5. 秩与自由变量的直觉

矩阵的**秩** = 线性无关的行（或列）的最大个数：
- 满秩（rank = n）：唯一解
- 缺秩：无穷多解或无数解，自由变量个数 = n − rank

### 6. 向量空间与基

判断一组向量是否构成基：线性无关 + 能张成空间。等价地，n 个 n 维向量线性无关 ⇔ 组成的矩阵行列式 ≠ 0。

### 7. 正交与投影

正交向量内积为 0。投影公式：

$$\text{proj}_u(v) = \frac{v\cdot u}{u\cdot u}\,u$$

最小二乘、正交分解、Gram-Schmidt 都是它的延伸——**投影是把向量分解到"保留信息最多的方向"**。

### 常见陷阱

1. **矩阵乘法不满足交换律**：AB ≠ BA，顺序不能随意换
2. **消元时把行变换和列变换混淆**：解方程只能用行变换
3. **特征向量漏掉零向量**：特征向量必须非零
4. **可逆条件记错**：可逆 ⇔ det≠0 ⇔ 满秩 ⇔ 列向量线性无关
